Szybki start

Skopiuj plik, podmień treści i wrzuć na Netlify/Vercel. Poniżej przykład minimalnej struktury projektu.

project/├─ index.html└─ public/   └─ favicon.svg

Instalacja (opcjonalnie z Vite)

npm create vite@latest my-app -- --template vanillacd my-appnpm i -D tailwindcss@latest postcss autoprefixernpx tailwindcss init -p

Ten szablon działa też bez buildu (CDN), więc możesz go używać jako czysty HTML.

FAQ

Czy mogę użyć tego w komercyjnym projekcie?

Tak, to neutralny szablon. Pamiętaj, by nie kopiować znaków towarowych ani oryginalnych treści innych stron.

Czy potrzebuję bundlera?

Nie, działa z samym CDN Tailwinda. Bundler ułatwia większe projekty.

Jak wdrożyć?

Wrzuć repo do GitHub i podłącz w Netlify/Vercel/Cloudflare Pages — jeden klik i gotowe.

Czy jest ciemny motyw?

Tak, przełącznik u góry zapisuje preferencję w localStorage.
